# 詳細設計書: `src/components/StageProduction.tsx`

## `function StageProduction()`

### 1. 概要
ゲームのボルテージ（コンボ数）および楽曲の進行（サビ）に同期して、3D シーン全体の視覚演出を動的に統合・制御する演出エンジンです。

### 2. 演出制御ロジック仕様

#### 2.1. 演出レベル算出 (`calculateFinalLevel`)
- **ベース入力**: `useGameState` から取得する現在の `productionLevel` (1〜4)。
  - 1: 0コンボ
  - 2: 1〜9コンボ
  - 3: 10〜19コンボ
  - 4: 20コンボ以上
- **サビ・ブースト**: 楽曲の `chorus` (サビ) 区間内では、ベースコンボ数に関わらず強制的に **レベル 4** を維持する。
- **ヒステリシス**: サビが終わった直後の一定期間（クールダウン）は急激に演出を下げず、余韻を保つための緩和処理を行う。

### 3. 個別演出モジュールの仕様

#### 3.1. ダイナミック・ライティング (`DynamicLights`)
- 演出レベルに応じて `AmbientLight` (環境光) の基調色と `SpotLight` の強度を補間計算する。
- **フラッシュ演出**: 演出レベル 4 においては、ダウンビートに合わせたパルス状の色変化（フラッシュ）を発生させ、視覚的なインパクトを最大化する。

#### 3.2. 観客ペンライト (`AudiencePenlights`)
- **レンダリング**: パフォーマンス向上のため、数千本のペンライトを `InstancedMesh` (GPU インスタンス描画) で一括処理する。
- **アニメーション**: 演出レベルに応じて揺れる速度と振幅を変化させ、「観客の盛り上がり」を表現する。
- **カラー同期**: サビ前では楽曲のテーマカラー、サビ中では暖色と寒色の混ざり合いなど、楽曲の展開に合わせた配色アルゴリズムを保持する。

#### 3.3. サイバー背景 (`CyberBackground`)
- `ShaderMaterial` を用いた床面と背景のグリッド演出。
- 演出レベルの上昇に伴い、グリッドの流動速度 (`uTime` スケーリング) と発光輝度を上げ、没入感を高める。

### 4. カメラ演出
- 高コンボ時やサビの開始時など、視覚的アクセントとして微細な「カメラシェイク」を発生させる。
