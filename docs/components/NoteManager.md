# 詳細設計書: `src/components/NoteManager.tsx`

## `function NoteManager({ handsDataRef }: { handsDataRef: BothHandsDataRef })`

### 1. 概要と役割
楽曲データの歌詞情報（Word/Char）をベースに、プレイヤーの前に流れてくる「ノート（Note）」のライフサイクルを管理するオーケストレーターです。

### 2. ライフサイクル仕様
- **初期化**: 楽曲のメタデータ読み込み完了時 (`isVideoReady`) かつ再生開始時に、難易度に応じたマージ済みノーツリストを生成する。
- **クリーンアップ**: 楽曲停止・切り替え時には、現在画面上に存在するすべてのノーツおよび付随する HTML 参照（判定ガイド等）を即座に破棄しなければならない。
- **同期維持**: 楽曲のシーク（巻き戻し・早送り）を検知した場合、内部の処理インデックスを適切な位置まで瞬時にロールバックまたはスキップさせる。

### 3. 主要ロジック仕様

#### 3.1. ノーツマージ (`mergeUnits`)
難易度設定の `mergeCount` に基づき、複数の時間的に近接した歌詞ユニットを 1 つの視覚的ノーツに結合する。
- **結合単語の保持**: 結合されたノーツがヒットした際に、元のすべての単語が「ヒット済み」としてマークされるよう、元の `startTime` 全てを `sourceStartTimes` として保持する。

#### 3.2. 指揮パターン割り当て
ノーツの出現位置 (`targetX/Y`) は、3x3 グリッド座標に準拠した `CONDUCTOR_PATTERN` 定数から循環的に選択される。
- **ミラーリング**: 左手用のパターンは、右手用を中央（X=0）に対して反転させたものでなければならない。

#### 3.3. タイミングガイド (`TimingStar`)
現在時刻から「次に叩くべきノーツ」の位置までを線で結び、その上を移動する星型アイコンを描画することで、プレイヤーに次のアクション位置を予見させる。
- **移動補完**: 直前のノーツ判定位置から次のノーツ判定位置まで、指定された秒数（`DEFAULT_SPAWN_AHEAD_MS`）をかけてスムーズに移動する。

### 4. 内部関数 (Inter-module Contract)

- `handleHit(id, hand)`: ヒット判定時に `onHit` アクションを呼び出し、該当ノーツを「ヒット状態」アニメーションへ移行させる。
- `handleMiss(id, hand)`: ノーツが判定限界時間を超過した場合に `onMiss` を呼び出し、フェードアウトさせる。
