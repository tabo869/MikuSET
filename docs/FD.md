# 機能仕様書 (FD) - MikuSET

## 1. システム概要
MikuSETは、ReactとTypeScriptで構築されたブラウザベースの音楽リズムゲームです。プレイヤーは楽曲に合わせて画面上に出現する「歌詞ノート」に対して、仮想インプット（ポインターやハンドトラッキング等のジェスチャー）を用いてタイミング良くアクションを行い、スコアを獲得します。

## 2. 目的とターゲット
* **目的**: 音楽とプレイヤーのアクション、及び画面上の演出（Stage Production）を同期させ、高い没入感のあるリズムゲーム体験を提供する。
* **ターゲット**: ブラウザで手軽にリズムゲームを楽しみたいユーザー。

## 3. 主要機能一覧

### 3.1. 楽曲管理・再生機能 (Music Management)
* 事前に登録された楽曲リスト（`songs.ts`）から楽曲を選択・再生できる。
* Piapro等の外部音源URLを指定しての再生に対応する。
* 楽曲の再生・一時停止・停止などのコントロール機能を提供する。

### 3.2. リズムゲーム機能 (Core Game Mechanics)
* **ノート出現**: 楽曲の進行（TextAlive API）に合わせて、歌詞やリズムを示す「ノート（Note）」が画面上に出現する。
* **ヒット判定**: プレイヤーが適切なタイミングでノートに対してアクション（左手/右手によるタップ・スワイプ等）を行ったかを判定する。判定範囲は 3D 空間の物理距離に基づく。
* **判定処理**: 成功した場合は「HIT」、タイミングを逃した場合は「MISS」とする。
* **難易度システム**: 4段階（Easy, Normal, Hard, Very Hard）の難易度設定を提供。
    * **密度調整**: 歌詞の最小単位（単語/文字）と、それらを結合する「マージカウント」を調整することで譜面の密度を変化させる。
    * **動的パラメータ**: 難易度に応じて、ノーツの流動速度（Speed）、判定範囲（Radius）、ポインターへの吸着力（Magnet Power）、出現軌道、判定猶予（Timing Window）が変動する。

### 3.3. インプットシステム (Input System)
* **ハイブリッド入力**: 
    * **Hand Tracker(AI)**: WebカメラとMediaPipeを用いた高精度なハンドトラッキング。
    * **仮想インプット**: キーボード（WER/ASDF等）やクリック、画面タップによる3D空間への座標投影。
* **キャリブレーション機能**: ユーザーのカメラ画角や腕のリーチに合わせ、画面の四隅に対して操作有効領域（Bounds）を設定・保存できる。
* **座標マッピング**: 入力された 2D 座標を、キャリブレーション情報を用いて Three.js の 3D ワールド座標系（判定エリア）にリアルタイムでマッピングする。

### 3.4. スコア・コンボシステム (Score & Combo)
* **スコア加算**: ノートを「HIT」した際に基礎点（100点）およびコンボボーナス（コンボ数 × 10点）を加算する。
* **コンボ管理**: 連続してHITに成功するとコンボ数が増加し、MISSとなるとコンボ数がリセットされる。
* **最大コンボ記録**: プレイ中の最大コンボ数を常時記録・保持する。

### 3.5. 演出システム (Stage Production)
* **演出レベル（Production Level）**: プレイヤーのコンボ数に応じてゲーム内の視覚・演出負荷を段階的に切り替える。
    * 初期・MISS時: **Level 1** (デフォルトライティング, 最小ペンライト)
    * コンボ開始 (1〜9): **Level 2**
    * 10コンボ以上: **Level 3**
    * 20コンボ以上: **Level 4** (最大光量, 全ペンライト稼働)
* **サビ同期ブースト**: 楽曲の「サビ（Chorus）」区間においては、コンボ数に関わらず強制的に演出レベルを最大（Level 4）に引き上げ、最大の盛り上がりを視覚的に演出する。
* **演出フィードバックの強化**:
    * **ライティング**: レベルに合わせた環境光の色変化と点滅・フラッシュ処理。
    * **観客ペンライト**: インスタンスメッシュを用いた数千本のペンライト。曲の雰囲気やサビに応じた自動色変更。
    * **サイバー背景**: 演出レベルに応じたシェーダーアニメーションの加速。

## 4. UI/UX 仕様

### 4.1. HUD (ヘッドアップディスプレイ)
* 画面上に現在の「スコア」、「コンボ数」、「最大コンボ数」をリアルタイムで表示する（`ScoreHUD`）。
* UIはゲームプレイの邪魔にならないよう、透過やアニメーションを活用したモダンなデザインとする。

### 4.2. フィードバックとレスポンス
* HIT時には視覚的（エフェクト）なフィードバックを即座に返す。
* MISS時にはコンボが途切れたことを示す明確な視覚的変化を与える（演出レベルの低下など）。
