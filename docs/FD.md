# 機能仕様書 (FD) - MikuSET

## 1. システム概要
MikuSETは、ReactとTypeScriptで構築されたブラウザベースの音楽リズムゲームです。プレイヤーは楽曲に合わせて画面上に出現する「歌詞ノート」に対して、仮想インプット（ポインターやハンドトラッキング等のジェスチャー）を用いてタイミング良くアクションを行い、スコアを獲得します。

## 2. 目的とターゲット
* **目的**: 音楽とプレイヤーのアクション、及び画面上の演出（Stage Production）を同期させ、高い没入感のあるリズムゲーム体験を提供する。
* **ターゲット**: ブラウザで手軽にリズムゲームを楽しみたいユーザー。

## 3. 主要機能一覧

### 3.1. 楽曲管理・再生機能 (Music Management)
* 事前に登録された楽曲リスト（`songs.ts`）から楽曲を選択・再生できる。
* Piapro等の外部音源URLを指定しての再生に対応する。
* 楽曲の再生・一時停止・停止などのコントロール機能を提供する。

### 3.2. リズムゲーム機能 (Core Game Mechanics)
* **ノート出現**: 楽曲の進行に合わせて、歌詞やリズムを示す「ノート（Note）」が画面上に出現する。
* **ヒット判定**: プレイヤーが適切なタイミングでノートに対してアクション（左手/右手によるタップ・スワイプ等）を行ったかを判定する。
* **判定処理**: 成功した場合は「HIT」、タイミングを逃した場合は「MISS」とする。

### 3.3. インプットシステム (Input System)
* **仮想インプット**: マウスやタップなどの既存インターフェースに加えて、バーチャルな入力（Hand Tracker等）を受け付ける仕組みを提供する。
* **座標マッピング**: 入力された物理的・仮想的な座標を、画面上のノート座標系（判定エリア）にマッピングして同期する。

### 3.4. スコア・コンボシステム (Score & Combo)
* **スコア加算**: ノートを「HIT」した際に基礎点（100点）およびコンボボーナス（コンボ数 × 10点）を加算する。
* **コンボ管理**: 連続してHITに成功するとコンボ数が増加し、MISSとなるとコンボ数がリセットされる。
* **最大コンボ記録**: プレイ中の最大コンボ数を常時記録・保持する。

### 3.5. 演出システム (Stage Production)
* プレイヤーのコンボ数に応じてゲーム内の「演出レベル（Production Level）」を切り替える。
    * 初期・MISS時: Level 1
    * コンボ開始 (1〜9): Level 2
    * 10コンボ以上: Level 3
    * 20コンボ以上: Level 4
* 演出レベルが上がるごとに、背景やエフェクト（Scene連携）を豪華にしてフィードバックを強化する。

## 4. UI/UX 仕様

### 4.1. HUD (ヘッドアップディスプレイ)
* 画面上に現在の「スコア」、「コンボ数」、「最大コンボ数」をリアルタイムで表示する（`ScoreHUD`）。
* UIはゲームプレイの邪魔にならないよう、透過やアニメーションを活用したモダンなデザインとする。

### 4.2. フィードバックとレスポンス
* HIT時には視覚的（エフェクト）なフィードバックを即座に返す。
* MISS時にはコンボが途切れたことを示す明確な視覚的変化を与える（演出レベルの低下など）。
