# MikuSET 開発・デバッグマスターナレッジ (Skills & Knowledge)

本ドキュメントは、MikuSET の開発において蓄積された重要なバグ修正パターン、TextAlive API の挙動特性、および最適な実装手法をまとめた「スキル」である。

---

## 1. 楽曲データの不整合と補正 (Broken Data Handling)

### 【重要】TextAlive API のデータ破損パターン
*   **現象**: 特定の楽曲で歌詞のタイミングが 1ms (0.001s) に収束し、ノーツが瞬間的に大量発生（データ爆発）したり、逆に消失したりする。
*   **解決策**:
    *   `onVideoReady` 内で、`duration <= 10ms` の文字データを異常値として検知し、フィルタリングする。
    *   破損区間（主にコーラス/サビ）に対しては、`chorus_override.ts` に定義した**精密タイミングデータ**を注入し、オリジナルの壊れたデータと差し替える。
    *   10ms以内の同一時刻に存在する文字は「重複」とみなし、`Set` を用いて排除する。

## 2. 難易度とノーツ生成 (Difficulty & Sync)

### 難易度変更の確実な反映
*   **特性**: 判定速度や統合数（mergeCount）などの設定値は `Ref` で管理されているため、React の `useEffect` で直接監視できない場合がある。
*   **解決策**:
    *   **100ms 間隔のポーリング (`setInterval`)** を用い、現在の難易度設定に変更がないかを常時監視する。
    *   変更を検知した瞬間、`initializedRef` を `false` にし、`setActiveNotes([])` を実行してノーツを強制再生成させる。

### 文字単位と単語単位の使い分け
*   **Easy/Normal**: `textUnit: 'word'` を使用し、意味のある塊で叩かせる。
*   **Hard/Very Hard**: `textUnit: 'char'` を使用し、一文字ずつ叩く高密度なプレイを実現する。

## 3. 歌詞表示と演出 (Lyric Display & UX)

### 表示状態の永続化 (Persistence)
*   **問題**: ポーズや再開時にスクロール歌詞が消える。
*   **解決策**:
    *   コンポーネントを `return null` でアンマウントしない。
    *   `isVisible` フラグと CSS の `opacity` で見た目のみを制御し、内部の `pastLines` (過去歌詞リスト) や `globalScrollRef` (位置情報) を保持し続ける。

### スクロールタイマーのリセット
*   **問題**: 曲のリピート時にスクロールが異常な速さになる。
*   **解決策**:
    *   曲の開始（`now <= 10ms`）を検知した際、`lastTimestampRef.current` を `null` にリセットし、前回のプレイ時刻との差分計算を防止する。

### 歌詞の送り出し (Pushing Logic)
*   **間奏**: 次の歌詞まで 1.5秒以上の空きがある場合、現在の一節を即座に上部へ送り出す。
*   **曲の終端**: 楽曲終了の 100ms後、または `duration` 直前に、最後の一節を強制的に送り出すことで、リザルト画面に歌詞が残るのを防ぐ。

## 4. システム安定化 (System Stability)

### 再生ブロックの回避
*   **問題**: ブラウザの制限で音声が再生されない (`NotAllowedError`)。
*   **解決策**:
    *   ユーザーのクリックイベント（STARTボタン）の**直後、同期的**に `actions.play(true)` を呼び出す。
    *   非同期処理（カウントダウン等）の前に一度 `play()` を呼ぶことで、ブラウザの「ユーザー操作による再生」のフラグを有効化する。

### ノーツの消え残り防止
*   **問題**: 曲が終わっても画面上にノーツや判定文字が残る。
*   **解決策**:
    *   `MusicManager` の `handleStop` またはリザルト表示トリガー時に、`document.querySelectorAll` を用いて、残存している HTML/CSS 要素を直接 `display: none` に書き換える。
