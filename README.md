# MikuSET (Miku Spectator Event Tool)

## 📌 作品タイトルと概要
### 「観客としてライブを演出する」全く新しいファン体験
従来の音楽ゲームは「演奏者」として正確にノーツを叩くものがほとんどでした。しかし『MikuSET』は、**「観客（オーディエンス）としてライブを熱く演出する」**という画期的なコンセプトから生まれた、新感覚のスペクテイター（観客）体験型リズムアクションゲームです。

初音ミクの歌声とステージの盛り上がりに合わせ、両手のペンライト（バトン）を振ることで、ステージの照明が激しくフラッシュし、パーティクルが飛び散り、ライブ空間全体があなたの「応援」によって鮮やかに彩られていきます。
初音ミクと同じライブ空間に立ち、観客の熱狂的な演出（Baton Swing）そのものをリズムアクションへと昇華させることで、単にゲームをプレイする以上の「一体感」と「圧倒的なライブ熱量」を生み出します。

---

## 🏆 審査基準に対するアピールポイント

### 🎨 1. クリエイティビティ（楽曲同期と演出の魅力）
* **TextAlive App API と WebGL Stage の完全同期**:
  - 再生されている楽曲のビート、メロディ、歌詞、そしてサビ（コーラス）情報と、Three.js で描画された3Dライブステージがリアルタイムで完璧にシンクロします。
  - サビに入った瞬間にステージの照明（スポットライト）が鮮やかに切り替わり、ミクの周囲に巨大なホログラム歌詞の3Dサークルが出現するドラマチックな演出を実装。
  - ユーザーがペンライト（バトン）を振る応援アクションに応じて、ビートに同期した無数の星型パーティクルや光のラインが炸裂し、プレイヤー自身の応援がそのままライブの視覚演出となる魅力的な共創体験を生み出します。

### 💡 2. イノベーション（ユニークなアイデアと未来の創作文化）
* **「観客主導型」のライブ共創という新しいパラダイム**:
  - 受動的に音楽を聴く、あるいは「プレイヤーとして楽曲を演奏する」のではなく、ファン自身が「ライブの熱量を演出し、共につくる一員」として参加する新しいコンテンツ体験を提案しています。
* **「マジカルゲストモード」がもたらす共生と多様性の未来**:
  - 手足を動かすことが難しく寝たきりの状態であっても、顔の表情（まばたき・口角の上げ下げ・口の開閉）を動かすだけで、Webカメラを通じてリアルタイムにパーカッションSEや3Dエフェクトを鳴らしてライブを一緒に盛り上げられるバリアフリー思想の具現化。
  - これは、「特定のスキルのある人だけが楽しめるゲーム」という枠組みを超え、「すべての人が自分のできる表現方法で共に音楽ライブイベントに参加し、創作・応援文化を楽しめる」という、未来の多様なユニバーサルデザインのあり方を予感させるユニークなアイデアです。

### 🛠️ 3. 完成度（技術的優位性とマルチデバイス対応）
* **ブラウザ上で100%滑らかに動作する高パフォーマンス**:
  - 非常に高負荷な「MediaPipeによるAIハンドおよびフェイストラッキング」と「Three.jsによるWebGL 3D描画」を同一ブラウザ内で動かしながら、フレームレート低下を防ぐために React State の不要な再描画を徹底排除（`useRef` のフル活用）。
  - バトンの動きに `Lerp`（線形補間）を適用することで、低スペックなWebカメラ環境でも滑らか（60fps相当）に追従する優れた描画パフォーマンスを実現しました。
* **どのような環境でも100%動作する堅牢なマルチ入力設計**:
  - Webカメラ（ハンドトラッキング）のほか、スマートフォンやタブレットでの「マルチタッチ操作」、PCの「キーボード操作」のすべてに対応したハイブリッド操作設計。
  - 3Dプロジェクション技術により、スマートフォンのアスペクト比変化やPCでの全画面表示（F11）の切り替えが起きても、タップ領域やガイド枠、文字の位置が1pxのズレもなく完全に重ね合わされて追従し、HUD操作（中断など）を絶対にブロックしない極めてバグの少ない高精度なレイアウト実装を完了しています。

## ⚡ 技術的アピールポイントと工夫

### 1. Webカメラのみで実現する「超高速ハンドトラッキング」
MediaPipeを活用した手の姿勢推定（Hand Landmark Detection）をベースとし、特殊なセンサー不要で、ノートPCの内蔵カメラやWebカメラだけで高精度な両手のモーショントラッキングを実現しています。

### 2. 「激甘判定」による圧倒的な爽快感の演出
初心者はもちろん、誰がプレイしても「ライブを盛り上げている楽しさ」を即座に味わえるよう、判定窓（Timing Window）や当たり判定の半径をあえて非常に広くした**「激甘判定」**を採用しています。
少し大雑把にペンライトを振るだけでも、心地よいヒット音が鳴り響いて初音ミクが応えてくれるため、抜群の「爽快感」と「肯定感」を味わえます。

### 3. ラグ対策としての `useRef` と `Lerp`（線形補間）の活用
ブラウザ環境およびWebGL（React Three Fiber）上の描画負荷によるフレームレート低下（ラグ）を徹底的に対策しています。
- **`useRef` によるポーリングの削減**: React の再レンダリングによるDOM負荷を避けるため、手の座標やバトンの軌跡データ、TextAlive の再生進捗をすべて `useRef` で管理し、毎フレームの React State 更新コストをほぼゼロに削減しました。
- **`Lerp`（線形補間）によるヌルヌル動くバトン軌跡**: トラッキングで得られた手の座標に線形補間（Lerp）を適用して中間フレームを補完することで、カメラの解像度が低かったりフレームレートが不安定であったりしても、バトンの3Dモデルが滑らか（ヌルヌル）に追従し、美麗な光のウェーブ（トレイル効果）を描き出します。

### 4. 完璧な同期を実現する「3D-2Dリアルタイムプロジェクション方式」
キーボード・タッチ入力時に表示されるグリッドやキー文字が画面の拡大縮小・フルスクリーン化によってズレるのを防ぐため、3D空間上のプレイ枠の四角座標を Three.js の `project` メソッドでリアルタイムに画面の2Dピクセル座標へ射影し、HUDレイヤに反映しています。これにより1pxのズレもはみ出しも起きず、背後の「中断」ボタンなどのUI操作も一切邪魔しない極めて堅牢なハイブリッド入力を実現しました。

## ♿ 心を繋ぐ「マジカルゲストモード」
### 寝たきりで表情を動かせる友人のために開発された、優しさと未来 of バリアフリー設計
このゲームには、**「手足を動かすことが難しく寝たきりの状態であっても、顔の表情を動かせる友人に向けて、一緒に初音ミクのライブを全力で楽しんで盛り上がってほしい」**という強い願いから生まれた **「マジカルゲストモード」** が搭載されています。

* **WebGL と Webカメラによる「表情（フェイス）トラッキング」**:
  - Webカメラを通じた高速なフェイストラッキング技術により、プレイヤーの顔のパーツの動き（まばたき、口角、口の開閉）をリアルタイムに検知します。
* **表情の動きと連動する3種のパーカッションSE ＆ 3Dパーティクル演出**:
  手や体を一切動かす必要はなく、カメラに向かって自分の表情を動かすだけで、それぞれ異なるパーカッション音とエフェクトが発生してライブに参加できます：
  1. **まばたき (Wink)**: タンバリンの軽快な音とともに、視線の先からきらめく光のリングが炸裂します。
  2. **口角の上げ下げ (Smile)**: カウベル（ウッドブロック）の音とともに、躍動感のあるスターパーティクルが周囲に広がります。
  3. **口の開閉 (Mouth Open/Close)**: シェイカーの心地よい響きとともに、ステージ上から眩い光のオーラが立ち上ります。
* **オートプレイ ＋ 演出参加システム**:
  - マジカルゲストモードを有効にすると、ノーツ判定がすべてオート（自動完璧ヒット）になります。ゲームオーバーのプレッシャーやミスによるストレスは一切ありません。
* **自分だけのタイミングでライブを彩る**:
  - 「寝たきりの状態でも、自分の意思で表情を動かして音を鳴らし、エフェクトを発生させてミクのステージを直接彩る」ことができます。このバリアフリー設計により、身体の可動域にかかわらず、「自分もこのライブを一緒に作っている！」という感動と楽しさを100%共有できます。

## 🚀 起動方法 (ローカル環境用)
審査員様の手元で動かせるよう、以下の手順で簡単に起動できます。

1. **パッケージのインストール**:
   リポジトリのルートディレクトリで以下のコマンドを実行し、依存パッケージをインストールします。
   ```bash
   npm install
   ```

2. **開発サーバーの起動**:
   インストール完了後、ローカル開発サーバーを立ち上げます。
   ```bash
   npm run dev
   ```

3. **ブラウザでのアクセス**:
   起動後、ターミナルに表示されるアドレス（デフォルトは `http://localhost:5173`）をブラウザで開きます。
   ※ カメラを使用するため、ブラウザからのカメラアクセス権限の要求を許可してください。

## 🎮 操作方法

ゲーム起動後、右上の設定パネルから3つの操作モードを切り替えてプレイできます。

### 👐 1. ハンドトラッキングモード（カメラ操作）
* Webカメラの前に立ち、カメラに両手が映るようにします。
* 画面上に青（左手）と赤（右手）のガイドライン（3D空間上に配置されたプレイ枠）が表示されます。
* 曲が始まると、歌詞ノーツ（星型ターゲット）が9分割エリアのいずれかに向かって飛んできます。
* ノーツが枠の中心（アルファベットキーが表示されている位置）に重なるタイミングで、**その手の側のペンライト（バトン）を「シュッと振る（スイングする）」**ことでヒット判定になります。

### 📱 2. タッチ操作モード（スマートフォン・タブレット等）
* 画面に表示される 3x3（左手用9分割・右手用9分割）のエリアを直接指でタップします。
* 歌詞ノーツがキー文字の真ん中に重なるタイミングで、対応するセルをタップしてください。
* マルチタッチに対応しており、両手での同時タップも完璧に判定されます。

### ⌨️ 3. キーボード操作モード
* PCのキーボードを使って、9分割の配置に対応した以下のキーを押すことでプレイします。
  - **左手用エリア (左の3x3)**:
    - 上段: `W` (左) / `E` (中) / `R` (右)
    - 中段: `S` (左) / `D` (中) / `F` (右)
    - 下段: `X` (左) / `C` (中) / `V` (右)
  - **右手用エリア (右の3x3)**:
    - 上段: `U` (左) / `I` (中) / `O` (右)
    - 中段: `J` (左) / `K` (中) / `L` (右)
    - 下段: `M` (左) / `,` (中) / `.` (右)
* 歌詞ノーツが飛んできたセルのキーを、曲のリズムに合わせてタイミングよく押してください。
* タッチ操作と同様に、同時押しも正確に処理されます。

## 🛠️ 操作パネル（設定メニュー）ユーザーズマニュアル

画面の右側に表示されるコントロールパネルの各機能と調整用パラメータの解説です。お使いの環境に合わせて最適にカスタマイズできます。

| 項目名 | 設定タイプ | 機能説明 |
| :--- | :--- | :--- |
| **楽曲を選択** | プルダウン | コンテスト公認の全6曲の中からプレイする曲を切り替えます。切り替えると自動で対応する曲がロードされ、ボーカル背後の巨大スクリーンに「選択曲名」「アーティスト名」「難易度別のパーソナルベスト（ハイスコア）」が大写しになります。 |
| **難易度** | ボタン選択 | `Easy` (やさしい)、`Normal` (ふつう)、`Hard` (むずかしい)、`Very Hard` (超上級) の4段階から選択します。難易度が高いほどノーツ（歌詞）の間隔が細かくなり、判定の難しさがアップします。 |
| **判定調整 (ms)** | スライダー | 音声とノーツの視覚的な移動タイミングにズレ（ラグ）を感じる場合に調整します。遅延が大きいと感じる場合は `+` 側へ、ノーツが早すぎると感じる場合は `-` 側へスライドしてください（ミリ秒単位で調整可能）。 |
| **連打間隔 (ms)** | スライダー | ペンライトの振り（スイング）を検知した後の「再入力無効時間」をミリ秒単位で設定します。手が小刻みに震えてしまったり、素早く1回振ったつもりが2重に検知（チャタリング）されてしまう場合は、数値を上げることで誤検知を完全に防止できます。 |
| **スタート / 中断** | ボタン | ゲームの開始、およびプレイ中の強制中断を行います。 |
| **スイングテスト（感度設定）**| ボタン | カメラハンドトラッキング時に「どのくらいの強さでペンライトを振るとスイング（判定）として検知されるか」をテストして可視化する画面を開きます。感度の調整や、カメラが正しく自分の両手を認識しているかのチェックに役立ちます。 |
| **オートプレイ (演出確認用)** | チェック | 自動的にすべてのノーツを「PERFECT」タイミングで自動演奏するデモモードです。ゲーム操作をせず、初音ミクの歌声とステージの美しい光の演出をじっくりと観賞したい場合に便利です。 |
| **マジカル・ゲスト (自動演奏)** | チェック | 寝たきりで表情を動かせる友人のために設計されたバリアフリーモードです。ノーツ判定はすべてオートになり、カメラに向かって「まばたき」「口角の上げ下げ」「口の開閉」といった表情を動かすだけで、3種類の異なるパーカッションSEと美しい3D光エフェクトがリアルタイムに炸裂し、ライブステージの演出に参加できます。 |
| **キーボード・タッチ操作** | チェック | Webカメラ（ハンドトラッキング）を使用せず、キーボードやスマートフォンの画面タップで手軽に遊びたい場合にオンにします（カメラ使用が制限されているブラウザ環境やスマホプレイ時には必須です）。 |
| **歌詞の流れる表示を隠す** | チェック | 画面中央奥から流れてくる歌詞（ノーツ）表示を非表示にします。ライブ演出（ミクのダンスや照明エフェクト）だけをクリアに楽しみたい場合や、描画負荷を下げてより滑らかに動かしたい場合に有効です。 |
| **キーボードのキー文字を隠す**| チェック | 判定枠に表示されている「W, E, R...」などのアルファベットキー表記を非表示にします。スマートフォンでのタッチプレイ時には文字が消え、スッキリとクリアなライブ画面になります（※スマホやタブレットでは初期状態で自動的にオンになります）。 |
| **日本語 (JA) / ガイド表示** | チェック | それぞれ「日本語 / 英語のUI表示切り替え」および「プレイエリアの枠線やガイドラインの表示ON/OFF」を設定します。 |
